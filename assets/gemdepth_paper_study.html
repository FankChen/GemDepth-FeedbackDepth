0 · 一句话核心 & 动机

核心论点：视频深度要做到真正的 3D 时序一致，显式的相机运动 + 全局 3D 结构感知是前提——不能只靠 Transformer 在 2D 帧上做"时序平滑"。
他们批评现有两派：
  • 生成式（DepthCrafter/ChronoDepth/RollingDepth，视频扩散）：空间细节好，但时序差、又慢又吃显存。
  • 判别式（VDA/NVDS，加轻量时序模块）：高效，但只做 2D 隐式平滑，缺 3D 几何感知 → 相机旋转/大视角变化时崩，且过度平滑糊边界。
GemDepth 的解法 = 两个协同模块：
  • GEM 显式建模相机自运动，预测 6-DoF 位姿 + 全局尺度 → 注入"位姿感知的几何嵌入"，用物理约束代替盲目平滑。
  • ASTT 用 GEM 的运动先验，把时空建模拆成 temporal（几何对齐）+ spatial（细节精修）交替，同时拿到高保真 + 无闪烁。
它是通用框架，可挂到 DAv2 / VDA 两种 baseline 上（得到 GemDepth-DAv2 / GemDepth-VDA）。

2 · GEM 几何嵌入模块

目的：把抽象的相机自运动 → 具体的结构嵌入，给网络一个"米制感知的坐标系"。

怎么做（基于轻量 EfficientPoseNet）：
  • 一个 4 层交替注意力 transformer，处理一个可学习的 camera token t（注入到 F4 特征图）。
  • 融合帧内空间上下文 + 帧间时序运动 → 精炼 token t̂ → pose head 出 6-DoF 位姿 g ∈ ℝ⁷（旋转四元数 Q∈ℝ⁴ + 平移 T∈ℝ³）。
  • 投影到统一 canonical frame；用全局尺度因子归一化平移解决单目尺度歧义：
T̂ᵢ = Tᵢ / Z , 其中 Z = (1/N) Σᵢ ‖Tᵢ‖ （全局平均平移模长）
  • 把 Q（旋转）、T̂（归一化平移）、Z（尺度） 各自过 geometric MLP → 相机特征 F_cam，融合回主特征 F4。
  • 用尺度归一化的 GT 位姿监督 → 预测位姿天然在统一尺度空间，消除初始尺度不一致。
为什么重要：这是"用物理约束代替盲目平滑"的来源。消融里 GEM 额外带来 KITTI +7.5% / Sintel +10.1% AbsRel，只加 5ms。而且对位姿噪声很鲁棒（§8）。

3 · ASTT 交替时空 Transformer

输入 GEM 增强后的特征 F̂，加 RoPE（空间位置编码）+ Idx Embedding（帧序编码），然后交替两个阶段：

① Temporal Attention — 几何对齐

  • 重排特征，隔离时序依赖；用 GEM 的 6-DoF 运动先验，建立跨帧的显式点级对应（point-level correspondence）。
  • 做基于轨迹的特征聚合——只抓纯运动线索，避开复杂空间上下文干扰 → 保证结构一致 + 无闪烁。

② Spatial Attention — 结构精修

  • 在对齐后的时序特征上做全局信息交换，拆成：帧内空间注意力（局部布局）+ 帧间空间注意力（长程依赖）。
  • 聚合 3D 空间特征，增强高频表示，锐化结构细节。
交替逻辑：先几何对齐、再细节锐化 → 同时解决"细节保留 vs 时序稳定"的冲突。

4 · 损失函数（3.4）

L_total = L_ssi + α·L_gm + β·L_tgm + γ·L_cam （α=0.5, β=10, γ=0.2）
项含义权重
L_ssi尺度-位移不变损失（视差空间 s=1/d，MiDaS 家族）1
L_gm多尺度梯度匹配（MiDaS）0.5
L_tgm时序梯度匹配（来自 VDA）10
L_camGEM 位姿 Huber loss：L_rot + λ·L_trans（旋转+平移）0.2
对照你的实验：你的 VideoDepthLoss = 视差 SSI + 0.5·梯度匹配 + 10·时序 = 论文的 L_ssi + 0.5·L_gm + 10·L_tgm，权重完全一致，唯一少了 γ·L_cam（因为你没有 GEM 位姿模块）。所以你的 temporal baseline ≈ 论文"去掉几何那一支"的深度损失。

10.2 建议的实验路线（从便宜到贵，逐步逼近）

  1. [进行中] 同配方 temporal baseline：跟你的 multiscale 做受控对照，先回答"多尺度头 vs 普通 temporal 头"。
  2. ASTT 位置实验（低成本高回报）：论文 Table 7 说 early-stage 时空交互 >> decoder 内。你可以先验证"把时序模块前移到特征提取后"是否对 ConvNeXt 也成立。
  3. 加判别式 LR：新模块 1e-4 / backbone 1e-6（你现在全 1e-4）——低成本，可能稳。
  4. 引入 GEM（大件）：加位姿预测 + 几何嵌入 + L_cam。你的 6 个训练集大多有位姿 GT（VKITTI2/TartanAir/PointOdyssey/MVS/DR），正好做 Stage-1 几何监督。注意：50% 位姿注入就够（Table 9），不必全程。
  5. 两阶段训练：Stage1 带位姿的 5 集 → Stage2 冻结 GEM + 无位姿数据精修。
  6. 加长 N / 多分辨率：往 N=32、多分辨率靠拢（贵，最后做）。
对照硬规则：每加一件都要有同配方 baseline，才能 claim 该模块的增益（正如论文 Table 4 的加法式消融）。
做实验时要盯的口径坑：
  • 评测都在视差空间仿射对齐；你的 video-loss/temporal 输出视差 → 不取倒数。
  • 论文测序列上限 500 帧；你现在四集脚本用的是各自 json（kitti 110 / sintel 100 / bonn 110 / scannet 90）——跟论文 500 帧列不是同一列，比的时候注意对齐是哪张表。
  • vkitti 域内 dense 的"held-out"其实 train 见过（非真 held-out），只当 sanity；真泛化看四集 zero-shot。

一、TL;DR

Stage-1 复现成立，但按论文的 500 帧协议重测后成绩需要下调。 以 VDA-L 为起点从零训练 ASTT + GEM，20k 步后：室内两集（Bonn / ScanNet）已超过 VDA 起点并逼近论文的完整两阶段成绩； 室外两集（KITTI / Sintel）尚未超过起点——这个分裂几乎可以直接归因到 Stage-1 数据配比失衡（室内数据严重过量，VKITTI2 只有论文的 1/4）。 训练侧 quat 从 0.30 降到 0.004、pose_loss 降 75%，证明 GEM 的位姿监督真实有效而非摆设。
⚠ 相较 2026-08-17 版看板的三处修正
  1. 「两项都在 7% 内」不再成立：短协议下 KITTI 0.0778 vs 论文 0.074 只差 5.1%，但 500 帧协议下是 0.0862 vs 0.074 = +16.5%。见第三节。
  2. 「PointOdyssey 占 ~90%」是错的：那是没乘 RATIO 直接拿 clips 数算的。真实有效配比见第六节。
  3. Stage-2 的定性要改：不是「缺 IRS」，而是论文的 150K 野外立体视频从未公开，严格复现不可能。见第五节。

为什么帧数会系统性影响分数：eval.py 对整条序列拟合一组全局 scale+shift（视差空间 lstsq）再算 AbsRel。 序列越短，一组仿射参数越容易拟合得好；序列越长，模型的尺度漂移逐帧累积，一组全局仿射兜不住。 所以帧数越少，视频深度方法的分数系统性越好看——这不是噪声，是有方向的偏差。

Sintel 那 +0.2% 是个有用的对照：本次 DATASETS 里 Sintel 没切 500 协议，结果几乎不变（差异纯属 bf16 推理噪声）， 反证了流程本身没有引入偏差，其余三集的劣化是真实的协议效应。

★ 500 帧才是 GemDepth 的主场：GEM 提供的是跨帧几何一致性、对抗的正是长程尺度漂移。90～110 帧太短，根本测不出 GEM 的价值。

五、Stage-2-lite 已训完 待评测

⚠ 先讲清楚定性：论文的 Stage-2 无法严格复现，本实验只是「机制近似」。 论文 3.5 节：Stage-2 = 冻结 GEM + 微调其余，数据 = IRS 100K + 野外立体视频 150K（均无位姿 GT），总 940K 帧。
  • 那 150K 野外立体视频作者从未公开，官方 README 的 Training Data 只列了 7 个可下载的集，其中并无此项。
  • IRS 唯一下载入口是 OneDrive（GitHub 仓库只有代码），HuggingFace 无镜像。
因此结论中绝不能写「复现了 Stage-2」，只能写「Stage-2 机制的近似消融」。

Stage-2 到底在解决什么问题

Stage-2 修的是一个 训练-推理不一致： 
Stage-1 训练时： L_cam 用 GT 位姿监督 GEM → GEM 被拽向正确位姿
                → ASTT 消费的是接近干净的几何
推理时：         没有 GT 位姿 → GEM 自估位姿、必然有误差
                → ASTT 突然要在带噪几何上工作 ← 它没训过这个
Stage-2 冻住 GEM（固定住它含自身误差的输出），再微调 ASTT + head，强迫 ASTT 学会消费 GEM 的真实输出而非理想输出。 这也是为什么 Stage-2 的数据必须无位姿 GT——有 GT 就又把 GEM 拽回理想状态，洞就补不上。

旁证：论文 Table 5「20% 位姿噪声 → AbsRel 0.066→0.071，仅掉 7.6%」，这份鲁棒性正是 Stage-2 训出来的。

所以完整表述是：Stage-2 = 合成→真实的域适应 + 位姿噪声适应。我们只能做后者（没有任何真实数据），因此增益预期明显小于论文。

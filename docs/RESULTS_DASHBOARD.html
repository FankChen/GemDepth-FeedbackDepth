⑤ 关键发现

  • baseline 泛化极稳：KITTI 0.0677 ≈ VKITTI 0.0690，几乎无域 gap。
  • error-map 4 臂两域全劣：比 baseline 差 ~0.011–0.016 AbsRel，KITTI 与 VKITTI 一致 → 结构问题，非域迁移。
  • 域 gap 很小（val→kitti 仅 +0.003–0.008）→ 进一步排除"合成→真实"是主因。
  • em_rgbfeat 最稳：VKITTI AbsRel/δ1 + KITTI RMSE/δ1 皆 4 臂最优；em_rgb 最差。
  • 收敛相反：baseline 6k 收敛，error-map 训满才好 → refine 分支在过拟合训练序列，未带来泛化增益。
